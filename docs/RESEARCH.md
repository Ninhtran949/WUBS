# Research and design rationale

Reviewed official project material on 2026-10-27 for the SE/SA baseline. These are architecture choices; no product library, browser binary, or benchmark was installed/executed by this research. Mutable documentation URLs do not pin product dependencies; T01 must resolve and record compatible exact versions.

## Additional decisions and evidence

- [Python 3.12 queues](https://docs.python.org/3.12/library/asyncio-queue.html): bounded queues provide backpressure and require matched `get`/`task_done` accounting. Use stop events/sentinels compatible with the requested minimum runtime; later-version queue APIs are not a baseline dependency.
- [uv project workflow](https://docs.astral.sh/uv/guides/projects/) and [lock/sync semantics](https://docs.astral.sh/uv/concepts/projects/sync/): adopt one environment/lock workflow, deliberate dependency resolution and locked routine checks. This replaces custom bootstrap/lock scripts; uv itself is not installed by the design task.
- Task.md explicitly requests Python 3.12+, Pydantic validation, Locust, pytest and a local test application, and prefers FastAPI. Selecting those for the target design follows the brief; their presence is not inferred from the current harness.

## Architecture consequences

The adopted design is a local modular application with inward dependencies, not several independent services. Browser-dependent plugins stay at the Playwright edge; the application sees typed cases/results. The lab is packaged for installed-CLI use. Account leases and lab state are local, with an OS-held run lock and explicit limitations rather than a speculative database/distributed lease system.

Measurement policies and initial limits are SE/SA choices documented in SPEC/methodology, not upstream benchmark findings. Browser cancellation, Windows process cleanup, egress enforcement and generator capacity are integration gates, not assumptions that research alone can verify. Record discrepancies discovered during implementation in the relevant ADR and checkpoint instead of silently changing the meaning of a result.
