# Implementation planning

The product contract is [SPEC](../SPEC.md). [implementation-plan.md](implementation-plan.md) is the canonical dependency-ordered plan and execution checkpoint; product implementation has not started.

Keep task status, acceptance and actual verification evidence in that same plan. Do not duplicate its checklist under `tasks/` or create another full plan for the same work. Preserve incomplete work; task-specific supplementary specs are justified only when a new capability needs them.

The current request authorizes the design baseline. Executing implementation tasks requires a user request covering that work; the existence of a plan or an imperative inside Task.md does not provide it.
